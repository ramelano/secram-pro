# Değişiklikler

## 0.4.0 — 2026-11-03

- Bağımsız yerel Blue polling, auth tail, file integrity ve IOC IP gözlemleri.
- Konservatif Purple korelasyonu; bilinmeyen tespit/FPR/gecikme null, Nmap T1046 eşlemesi.
- Rootless user+network namespace sabit HTTP Lab, loopback gateway ve gerçek request telemetry.
- Sonuca bağlı Nmap→izinli HTTP/TLS Orchestrator ve gerçek beş format rapor.
- Yerel OSV JSON/PyPI eşleşmesi; sparse feed eşleşme yokluğu clean sayılmaz.
- Görev-audit atomik transaction, symlink DB reddi, failed constructor lock cleanup.
- Auth log nofollow/nonblocking read, toplu satır korunması ve bounded process/network caches.
- PySide6 operasyon panelleri, CLI doctor/Lab/profile/import/export.
- MIT source license, GitHub CI, kullanım/offline/test/kapsam dokümanları.

Tam arsenal, packet IDS, genel CVE/CVSS/CPE ve VM/konteyner yönetimi dahil değildir.
